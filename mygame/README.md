# Legal Test Game - Spelunky Classic HD (Open Source)

This is the open source remake of Derek Yu's Spelunky Classic.
- Original code: https://github.com/yancharkin/SpelunkyClassicHD
- Source published via Humble Bundle, maintained by yancharkin
- License: see LICENSE in mygame_src/

## How to build data.win for NebulaFD test:

1. Install GameMaker (free) on Windows: https://gamemaker.io
2. Open `mygame_src/SpelunkyClassicHD.yyp`
3. Build -> Create Executable -> VM (or export as zip)
4. Copy the built `data.win` to `mygame/data.win`
5. `git add mygame/data.win && git commit && git push` -> workflow will decompile it legally
